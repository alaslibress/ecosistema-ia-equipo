# ARQUITECTURA DE HARNESS Y SKILLS DE IA DEL EQUIPO
Entorno objetivo: Windows 11 ARM64 (Microsoft Surface) | Shell: PowerShell 7+
Rutas base: $env:USERPROFILE\.claude\ | $env:USERPROFILE\.claude-code-router\

================================================================================
NIVEL 0: INFRAESTRUCTURA GLOBAL (INSTALACIÓN OBLIGATORIA EN LAS 4 MÁQUINAS)
================================================================================
Propósito: Capa de sistema para optimización de costes, filtrado de contexto y bienvenida. No compite con las skills de rol.

1. Enrutador de Modelos: `@musistudio/claude-code-router` (CCR)
   - Ruta `background`: Claude Haiku (lectura de archivos, exploración, subagentes).
   - Ruta `default`: Claude Sonnet (ejecución diaria, código y tareas operativas).
   - Ruta `think`: Claude Opus (arquitectura, planificación compleja y auditorías).
2. Filtro de Terminal y Memoria:
   - `RTK (Rust Token Killer)`: Inicializado como hook global (`rtk init -g`) para comprimir entre un 60% y 90% las salidas de consola, tests y logs de red.
   - `Context Mode`: Limpieza activa de payloads masivos en la ventana de contexto y preservación de estado tras compactaciones.
3. Compresión de Salida:
   - `Caveman`: Configurado globalmente en modo `Lite` (elimina relleno conversacional y cortesías ahorrando tokens de salida, pero preserva el formato de tablas, informes SEO, código y explicaciones claras).
4. Onboarding Interactivo (Skill interna común):
   - `empezar` (`~/.claude/skills/empezar/SKILL.md`): Guía interactiva de 3 minutos en español adaptada al rol de cada máquina al ejecutar `/empezar`.

*Nota de Gobernanza Global:* Ninguna máquina instala `find-skill` salvo el Perfil 3 (Arquitectura), que actúa como aduana única auditando cada skill con `NVIDIA Skill Specter` (puntuación mínima exigida: 85/100) antes de distribuirla al resto del equipo.

PERFIL 4: GENERALISTA OPERATIVO — SISTEMAS, REDES Y AUDITORÍA (`setup-perfil-4-generalista-operativo.ps1`)
================================================================================
Rol: Técnico de sistemas/redes, auditoría administrativa de plantillas (Quiter/Drive) y creación de utilidades mediante Vibe Coding puro (usuario no programador).
Herencia: Nivel 0 completo (con `Caveman` bloqueado en modo `Lite` para garantizar explicaciones en español claro sin jerga de código).
PROHIBIDO INSTALAR: `hola-ai`, `Ponytail`, `Agent Skills (Addy Osmani)`, `Graphify`, `grill-me`.

1. Manipulación Directa de Documentos y Navegación:
   - `Anthropic Document Skills` oficiales (`docx`, `pdf`, `xlsx`) + paquetes base de Python (`python-docx`, `pypdf`, `openpyxl`, `pillow`): Lectura y edición directa de plantillas de Word/Drive, facturas/albaranes en PDF exportados de Quiter, hojas de control en Excel e inspección de dimensiones en píxeles de logos incrustados.
   - `Agent Browser`: Inspección asistida de carpetas en Google Drive, intranets y paneles web de routers/switches/sistemas.
2. Asistente Todoterreno (Skill interna autogenerada):
   - `asistente-operativo-it` (`~/.claude/skills/asistente-operativo-it/SKILL.md`), estructurada en 3 módulos de comportamiento:
     a) Módulo de Auditoría y Corrección de Plantillas (Quiter / Drive):
        - Cruza datos entre las sedes del grupo (`GR-32 Indese Industriales`, `Indese Turismos`, `GR-22`, `GRT-34`, `GRM-36-37`, `SURDAF-19`, `SALGAR-29`) y sus 4 departamentos (`Taller: oficina de taller`, `Recambios: ventas almacén`, `Comercial: facturas VO turismos`, `Conta: emisión facturas`).
        - Comprueba NIF, direcciones, teléfonos, datos registrales, tamaños/proporciones de logos y cuentas bancarias IBAN (verificando matemáticamente el dígito de control y asegurando que las cuentas más usadas lleven el asterisco `*`).
        - Muestra tablas resumen tipo semáforo (✅ Correcto / ❌ Discrepancia) y genera siempre una copia de seguridad (`_backup`) antes de modificar cualquier plantilla.
     b) Módulo de Soporte de Sistemas y Redes Seguro (Windows 11 ARM64):
        - Ejecuta diagnósticos de red, DNS, DHCP, VPN, firewall y eventos de Windows estrictamente en modo lectura primero (`Test-NetConnection`, `Get-NetAdapter`, `Get-WinEvent`).
        - Exige confirmación explícita del usuario explicando el impacto en lenguaje sencillo y utilizando `-WhatIf` en PowerShell antes de modificar configuraciones o reiniciar servicios.
     c) Módulo de Vibe Coding Transparente:
        - Cuando el usuario pida una pequeña herramienta o automatización, la IA elige la arquitectura autocontenida más simple, instala lo necesario, ejecuta y corrige cualquier error en silencio, y entrega el archivo o acceso directo listo para usar sin hacer preguntas técnicas de programación.
